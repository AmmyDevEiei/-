## ภารกิจที่ 3 (Mission 3 - ท้าทายสมอง): ทางลัดโดรนส่งพัสดุ (Drone Shortcut)

> **สถานการณ์:** รถส่งพัสดุต้องวิ่งไปตามถนนผังเมืองที่เป็นรูปตารางสี่เหลี่ยม โดยออกจากจุดศูนย์กระจายสินค้า (จุด A) วิ่งตรงไปทาง **ทิศตะวันออก $8$ กิโลเมตร** จากนั้นเลี้ยวขึ้นไปทาง **ทิศเหนืออีก $15$ กิโลเมตร** จึงจะถึงบ้านลูกค้า (จุด B)  
> วันนี้บริษัททดลองใช้ **"โดรนบินส่งของ"** ซึ่งสามารถบินตรงเป็นแนวเส้นตรงบนท้องฟ้าจากจุด A ไปยังจุด B ได้ทันที

## เฉลยแนวคำตอบและเกณฑ์การให้คะแนน (Scoring Guide)

### เฉลยคำตอบภารกิจทั้ง 3 ข้อ:
1. **ภารกิจที่ 1:**  
   * $a = 12$ ม., $b = 9$ ม.  
   * $c^2 = 12^2 + 9^2 = 144 + 81 = 225$  
   * $c = \sqrt{225} = 15$ เมตร  
   * **ตอบ:** บันไดกู้ภัยต้องยืดออกไปอย่างน้อย **$15$ เมตร**
2. **ภารกิจที่ 2:**  
   * 2.1: $a = 24$ ม., $b = 7$ ม. $\rightarrow c^2 = 24^2 + 7^2 = 576 + 49 = 625 \rightarrow c = \sqrt{625} = 25$ เมตร  
     *(สายสลิง 1 เส้นยาว $25$ เมตร)*  
   * 2.2: ขึง 4 ทิศ $= 25 \times 4 = 100$ เมตร  
     * **ตอบ:** ต้องใช้สายสลิงรวมทั้งหมดอย่างน้อย **$100$ เมตร**
3. **ภารกิจที่ 3:**  
   * รถวิ่งตามถนน $= 8 + 15 = 23$ กิโลเมตร  
   * โดรนบินตรง $c^2 = 8^2 + 15^2 = 64 + 225 = 289 \rightarrow c = \sqrt{289} = 17$ กิโลเมตร  
   * ระยะทางที่ประหยัดได้ $= 23 - 17 = 6$ กิโลเมตร  
   * **ตอบ:** โดรนช่วยประหยัดระยะทางได้ **$6$ กิโลเมตร**

| **1. ความถูกต้องทางคณิตศาสตร์ (P)**<br>*(4 คะแนน)* | แสดงวิธีทำละเอียด ถูกต้องครบถ้วนทั้ง 3 ภารกิจ ถอดรากและใส่หน่วยถูกต้อง | แสดงวิธีทำถูกต้อง 2 ภารกิจ หรือมีข้อผิดพลาดเล็กน้อยเรื่องการคำนวณ | แสดงวิธีทำถูกต้องเพียง 1 ภารกิจ ไม่ใส่หน่วย | ไม่สามารถแสดงวิธีทำตามขั้นตอนสูตรพีทาโกรัสได้ |
| **2. การเชื่อมโยงและแก้ปัญหา (K/P)**<br>*(3 คะแนน)* | วาดรูปจำลองแปลงโจทย์สถานการณ์เป็นสามเหลี่ยมมุมฉากได้ถูกต้องสมบูรณ์ทุกข้อ | วาดรูปจำลองและระบุด้านได้ถูกต้องเกือบครบทุกข้อ | วาดรูปจำลองไม่สมบูรณ์ ระบุด้านสลับกัน | ไม่สามารถเชื่อมโยงโจทย์สู่รูปเรขาคณิตได้ |
| **3. ทักษะการทำงานเป็นทีม (A/8Cs)**<br>*(3 คะแนน)* | สมาชิกทุกคนแบ่งหน้าที่ชัดเจน ช่วยเหลือกันอย่างกระตือรือร้น เสร็จทันเวลา | สมาชิกส่วนใหญ่ร่วมมือกัน ช่วยเหลือกันดี ทำเสร็จทันเวลา | ทำงานร่วมกันเฉพาะบางคน ไม่ค่อยปรึกษากัน ทำเสร็จช้ากว่าเวลาเล็กน้อย | ไม่ร่วมมือกันทำงาน เกี่ยงกันทำ ชิ้นงานไม่เสร็จ |
